# Beads by Rumi — Growth Edition V2

Static GitHub Pages website.

## Easy editing
- Product data: `products.js`
- Offers/discount banner: `offers.js`
- Product photos: `images/`

Change a product price, status, badge, description or image in `products.js`; the Shop, Featured section and Product Details page use the same data.
